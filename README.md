# 🌟 Random Quote Generator

A modern quote generator built with HTML, CSS, and JavaScript.

### ✨ Features
- 🔀 Random quotes with author
- 🎨 Dark / Light mode toggle
- ⭐ Save favorite quotes
- 🐦 Tweet current quote
- 💎 Glassmorphism UI with animated gradient background
